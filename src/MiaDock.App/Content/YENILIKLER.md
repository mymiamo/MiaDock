# What's New

## 1.4.1

- Improved resilience when Windows brightness keys are used while a media application is active.
- Hardened Core Audio and Windows media callbacks so a disappearing device or media provider cannot close MiaDock.
- Made USB removable-drive detection more reliable with safe periodic reconciliation.
- Added richer Microsoft Store update-check diagnostics.

## 1.4.0

- Refreshed dock transitions with Community Toolkit animations and smoother event-notification morphing.
- Added privacy indicators for applications using the microphone and camera.
- Added optional dock indicators for Caps Lock, Num Lock, Scroll Lock, and USB connect/disconnect events. They are enabled by default and can be turned off in Modules → Optional.
- Reorganized Settings; What's New is available in the sub-navigation and the Back action works consistently.
- Moved fullscreen settings under Personalization and kept shortcuts in their own section.

## 1.3.0

- Added controls for dock corner radius and the distance from the screen edge.
- Expanded fullscreen behavior options.
- Improved battery and Bluetooth status detection.
