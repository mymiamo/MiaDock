# MiaDock 1.2.0.0 Release Notes

## Türkçe

- Kişiselleştirilebilir Odak profilleri eklendi.
- Odak profilleri için süre, haftalık program ve uygulama tetikleyicileri eklendi.
- Profil başına dock görünürlüğü, modül filtresi, olay önceliği ve gizlilik seçenekleri eklendi.
- Windows Odak ayarlarına güvenli geçiş eklendi.
- Windows ana ses görünümü ve uygulama bazlı ses karıştırıcısı eklendi.
- Sistem tepsisi menüsü ve genişletilmiş dock tasarımı yenilendi.
- Ağ hız ölçümü ve Windows başlangıç görevi daha güvenilir hale getirildi.
- Modül servisleri ve izinleri için açıklayıcı kullanıcı akışı eklendi.
- Apple benzeri temada metin, ikon ve kontrol kontrastı iyileştirildi.
- Genel performans, yerelleştirme ve kararlılık düzeltmeleri yapıldı.

---

## English

- Added customizable Focus profiles.
- Added durations, weekly schedules, and application triggers for Focus profiles.
- Added per-profile dock visibility, module filters, event priority, and privacy controls.
- Added a safe shortcut to Windows Focus settings.
- Added the Windows master-volume view and per-application audio mixer.
- Redesigned the system tray menu and expanded dock experience.
- Improved network speed measurement and Windows startup-task reliability.
- Added explanatory service and permission flows for modules.
- Improved text, icon, and control contrast in the Apple-like theme.
- Added general performance, localization, and stability fixes.
