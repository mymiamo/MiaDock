# MiaDock 1.5.4.0 release notes

* Tray commands now use a semantic Fluent icon map backed by selected official SVG assets.
* Windows audio endpoint discovery uses NAudio; specialized mixer and media-session metering remain on their proven Core Audio path.
* WinUIEx runtime payload checks cover unpackaged and MSIX release validation.
* Duplicate platform references and an unused native declaration were removed.
